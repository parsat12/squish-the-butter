# squish the butter
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.0.

## Gameplay
Players start with 1 Plain Butter. Cracking butter gives a random Needoh prize.
Owned Needohs generate coins every second, and rarer Needohs generate coins faster.
Coins can be spent on better butter sticks with stronger odds for rare prizes.

Main files:

- `src/shared/GameConfig.luau`: butter costs, rarity odds, Needoh coin rates.
- `src/server/init.server.luau`: data saving, buying, cracking, and coin generation.
- `src/client/init.client.luau`: simple testing UI.

## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "squish the butter.rbxlx"
```

Next, open `squish the butter.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).
