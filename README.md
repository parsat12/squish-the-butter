# squish the butter
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.0.

## Gameplay
Players start with 1 Plain Butter. Cracking butter gives a random Beeboh prize.
Owned Beebohs generate coins every second, and rarer Beebohs generate coins faster.
Coins can be spent on better butter sticks with stronger odds for rare prizes.

Main files:

- `src/shared/GameConfig.luau`: butter costs, rarity odds, Beeboh coin rates.
- `src/server/init.server.luau`: data saving, buying, cracking, and coin generation.
- `src/client/init.client.luau`: inventory UI, butter preview, buying, and cracking.

## Beeboh Model Setup
Put your Beeboh models in `ReplicatedStorage.BeebohModels`. If you use Rojo,
that folder comes from `src/beebohModels`.

Name the models with these ids:

- `BlueBlob`
- `LemonSquish`
- `StrawberrySquish`
- `PicklePop`
- `JellyCube`
- `GlowOrb`
- `MetalBeeboh`
- `LavaLamp`
- `CloudPuff`
- `ClearBeeboh`
- `GoldfishBowl`
- `ButterKing`
- `GalaxyOrb`
- `SecretSentientButter`

Those names match the ids in `src/shared/GameConfig.luau`. The full display
names, like `Blue Blob Beeboh`, also work, but ids are easier to keep exact.

## Beeboh Inventory
Players can own up to 20 Beebohs at a time. The Beeboh inventory panel shows
each owned Beeboh, its rarity, and its coin rate. Players can delete Beebohs
from that panel to free space before cracking more butter.

## Butter Inventory Flow
The UI shows every butter type and how many the player owns. Clicking an owned
butter stick equips it into a center-screen preview. The player can then crack
that previewed butter to start a full-screen cracking sequence.

When the player clicks `Crack`, the selected butter model fills the screen. The
player clicks the butter three times, each hit showing a stronger crack stage.
On the third hit, the butter opens, the server rolls the Beeboh prize, and a
sparkly Beeboh reveal appears before the game returns to the inventory.

To use your own butter model in the preview:

1. Create a folder in `ReplicatedStorage` named `ButterModels`.
2. Put your butter stick model inside it.
3. Name the model after the butter id, such as `Plain`, `Salted`, `Golden`, `Rainbow`, or `Cosmic`.

The preview camera automatically zooms close to the model. If no matching model
exists in `ReplicatedStorage.ButterModels`, the UI will also look for a
`Workspace` model named `ButterStick` or `ButterStation` for `Plain` butter. If
it still cannot find one, it uses a simple generated butter stick preview.

## Butter Stick Model Setup
To use a 3D butter stick as the cracking station:

1. Put your model in `Workspace`.
2. Name it `ButterStick` or `ButterStation`.
3. Make sure the model has at least one `BasePart`.
4. Optionally add a `ButterId` attribute with one of these values: `Plain`, `Salted`, `Golden`, `Rainbow`, or `Cosmic`.

The server will automatically add a `ProximityPrompt`. When a player cracks it, a colored Beeboh prize pops out and the prize is added to their coin generation.

## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "squish the butter.rbxlx"
```

Next, open `squish the butter.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```
