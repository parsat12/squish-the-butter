# Beeboh Models

Put Beeboh models in this folder so Rojo creates `ReplicatedStorage.BeebohModels`.

Name each model with the Beeboh id from `src/shared/GameConfig.luau`, for example:

- `BlueBlob`
- `LemonSquish`
- `StrawberrySquish`
- `PicklePop`
- `JellyCube`
- `GlowOrb`
- `MetalBeeboh`
- `LavaLamp`
- `CloudPuff`
- `ClearBeeboh`
- `GoldfishBowl`
- `ButterKing`
- `GalaxyOrb`
- `SecretSentientButter`

The reveal also accepts the full display name, like `Blue Blob Beeboh`, but ids
are cleaner and safer.
